# React Standards

## Components

One component per file.

---

## Exports

Default export.

---

## Props

Keep components reusable.

---

## State

State belongs in the highest component that needs it.

---

## Rendering

Prefer map() over repeated markup.

---

## Naming

PascalCase for components.

camelCase for variables.

## Data

Do not hardcode portfolio information inside components.

Instead:

Component

↓

portfolio.js

↓

Render
