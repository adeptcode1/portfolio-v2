# Christopher Schaeffer Portfolio

## Overview

This repository contains the source code for my personal portfolio website.

The goal is to showcase my work as a Full-Stack Web Developer while demonstrating professional React architecture and modern web development practices.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React
- Apache Web Server
- Laravel (future backend)

## Goals

- Professional portfolio
- Business-oriented presentation
- Mobile-first responsive design
- Accessibility
- High Lighthouse score
- Easy future expansion
